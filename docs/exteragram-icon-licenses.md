# exteraGram interface icon assets

The unchanged SVGs in `Telegram/Telegram-iOS/Icons.xcassets/Extera{Solar,Remix}-*.imageset` are template glyphs for navigation.

- Solar Linear icons by 480 Design and Damir Tuarshe. [SVG source snapshot](https://github.com/480-Design/Solar-Icon-Set/tree/44017167688b49109d88ae6a98979b23d8950db0/icons/SVG/Linear) and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Remix Icon v4.6.0 by Remix Design. [SVG source](https://github.com/Remix-Design/RemixIcon/tree/v4.6.0/icons) and [Apache License 2.0](../Telegram/Telegram-iOS/Resources/ExteraRemix-LICENSE.txt).

The optional monochrome emoji face is [Noto Emoji by Google](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoemoji). The unmodified font and SIL OFL 1.1 license are part of the app resources as `ExteraNotoEmoji.ttf` and `ExteraNotoEmoji-OFL.txt`.
