# exteraGram iOS Port 0.1.0

## Рабочая база 0.0.5 Hotfix

Ветка `baseline/0.0.5-hotfix` закрепляет исходный коммит `5d9f1ca1e368a76c8bfd8f2c0058d533e6f73f50`, из которого выпущен Build 5. Установочный hotfix получен из этого IPA удалением `NSSiriUsageDescription` из основного `Info.plist` и 19 локализаций. SHA-256 рабочего IPA — `5bc30f4285647cd1266b82e77743ee15bac893355edc2c7d2a21a59dd551891b`. После входа приложение запустилось на iPhone X с iOS 16.3. Проверенный IPA хранится локально. [Сборка исходного IPA](https://github.com/z7413130-a11y/exteraGram-iOS/actions/runs/45827706037)

Дальнейшая разработка идёт от ветки `development/0.1.0`, созданной от проверенного коммита. В ней поведение hotfix закреплено в исходниках и в процессе сборки. Сборка для сторонней подписи пропускает авторизацию SiriKit. Конфигурация с назначенным правом Siri сохраняет исходный путь. Сборка для устройства использует идентификатор `org.exteragram.iosport`, iOS 15.0+, ARM64, шесть расширений, приватное резервное хранилище, защиту запуска без CloudKit и локальный журнал диагностики.

## Реализация 0.1.0 (Build 6)

В «Настройках» Telegram появился раздел exteraGram с категориями «Общие», «Оформление», «Чаты», «Плагины» и «Прочее». Модуль `ExteraSettings` содержит 175 типизированных ключей из Android и дополнительный ключ включения перевода черновиков. Значения хранятся отдельно в локальных настройках iOS и действуют для всех аккаунтов на устройстве. В интерфейс выведены настройки реализованных функций. Код Android служит справочником имён и типов. [Исходный ExteraConfig.kt](https://github.com/exteraSquad/exteraGram/blob/b4d852f48f2734a0bee1a74a0939be621612262a/TMessagesProj/src/main/java/com/exteragram/messenger/ExteraConfig.kt)

Имя основного пакета и отображаемое имя заданы как **exteraGram**, включая локализации, которые их переопределяли. Основная иконка использует исходное изображение проекта в размерах для iPhone и iPad. Имена и идентификаторы расширений сохранены. Для обновления поверх 0.0.5 Hotfix на том же устройстве потребуется совместимая подпись.

| Функция | Поведение |
| --- | --- |
| Сведения о сообщении | Отдельный пункт в контекстном меню обычного сообщения. Показывает ID, время отправки, автора, видимое время правки и доступные счётчики из локальных данных. |
| Боковая кнопка «Поделиться» | Настройка скрывает действие поделиться рядом с сообщением. Контекстное меню, переходы к ответам и к исходным сообщениям доступны. По умолчанию кнопка остаётся видимой для сохранения привычного поведения Telegram. |
| Перевод перед отправкой | Команда в меню отправки появляется после включения настройки. Для каждого запроса нужно подтвердить отправку черновика сервису перевода Telegram. Результат помещается в поле ввода. При ошибке, отмене или изменении черновика исходный ввод сохраняется. Для секретных чатов команда скрыта. |

## Дальнейший перенос

Настройки, интерфейс настроек, сведения о сообщении и перевод подключены отдельными целями Bazel. Для новых функций используем точку расширения штатного экрана и отдельный модуль с минимальным набором зависимостей. Для будущих настроек на аккаунт используем данные соответствующего `AccountContext`. Изменения схемы должны сохранять уже записанные значения.

Темы, плеер, тексты песен, настройки камеры и загрузок подключаем через штатные точки расширения с проверкой на iOS 15. Для плагинов отдельно исследуем перенос форматов и iOS API с явными разрешениями и возможностью отключения. [Функции оригинала](https://exteragram.app/) · [Релизы Android](https://github.com/exteraSquad/exteraGram/releases) · [Документация плагинов](https://plugins.exteragram.app/docs)

## Регрессии перед выпуском

Проверка `python3 build-system/Make/SideloadSiri.py check-source` запускается без компиляции. Она контролирует оба ранних выхода Siri и флаг в конфигурации. Будущий запуск IPA workflow обработает локализации до компиляции и проверит отсутствие ключа в готовом IPA перед сохранением артефакта. Для варианта с правом Siri следует подтвердить наличие ключа и системный сценарий разрешения.

| Проверка | Ожидаемый результат |
| --- | --- |
| Чистая установка на iPhone X с iOS 16.3, вход и открытие списка чатов | Список чатов открывается. В журнале запуска для сторонней подписи отмечена недоступность Siri. |
| Поверх 0.0.5 Hotfix с тем же Bundle ID, повторный запуск после закрытия | Аккаунт и локальные настройки доступны. Повторный вход не требуется. |
| TrollStore и обычная подпись, отдельно без App Group и с доступной App Group | Основное приложение запускается. Общие данные видны расширениям при разрешённой общей группе. Сборка оставляет все шесть расширений. |
| Сборка без права iCloud и без доступного APNs | Вход и открытие чатов работают. При недоступной регистрации уведомлений диагностика остаётся локальной. |
| Включение функций, выбор языка, перезапуск и переключение между аккаунтами | Выбор сохраняется и действует для всех аккаунтов на устройстве. Сброс восстанавливает значения по умолчанию. |
| Контекстное меню и боковая кнопка | Сведения доступны только после включения. Скрытие обычной кнопки «Поделиться» сохраняет контекстное меню, ответы и переход к источнику. |
| Перевод черновика | Согласие запускает запрос. Отмена, ошибка и запоздалый ответ после редактирования сохраняют ввод. В секретном чате команды нет. |
| Имя и основная иконка | На домашнем экране и в системных списках отображается exteraGram. На iPhone и iPad показана новая иконка. Из настроек оформления можно вернуться к основной иконке. |
| Структура IPA и символы | Проверены идентификаторы, ARM64, минимальная версия iOS, расширения и совпадающие UUID приложения, TelegramUIFramework и TelegramCoreFramework. |

Установочные проверки проводятся на физическом устройстве после плановой сборки. Запуск проверенного IPA 0.0.5 Hotfix и проверки нового исходного кода фиксируются отдельно.
